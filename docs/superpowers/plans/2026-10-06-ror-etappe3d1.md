# Rør, etappe 3d-1: plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kummer i 3D, høybrekk/lavbrekk og fallkrav for trykkrør, og grøftekasse og spunt i grøfta.

**Architecture:** Tre deler som ikke rører hverandre:
- `RorPlan.kontroller` (ren) får trykkrørkontrollen, med `brekk(z, h)` som egen funksjon.
- `Ror3d._overleggEkstra` tegner kummene som sylindre og ringer.
- `Groft` får avstiving per strekning. Den ligger som loddrette vegger på segmentene, med en avstivingssone som ingen skråning graver inn i.

UI, lagring, rapport, PDF og CSV følger mønsteret som finnes.

**Tech Stack:** Vanilla JS, ingen byggesteg. Modulene er objekter/IIFE-er med `if (typeof module !== 'undefined') module.exports = …`. Prøvene:
- node: `test/rorplanprove.js`, `test/groftprove.js`, `test/roreksportprove.js` og resten av `npm test`;
- nettleser: `public/js/nettlesertest.js`.

**Spec:** `docs/superpowers/specs/2026-10-06-ror-etappe3d1-design.md`

## Global Constraints

- Repoet er offentlig: ingen kundedata i commits. Prøvene bruker oppdiktede data.
- Ingenting her endrer høyder. Innmålte høyder endres aldri automatisk.
- Innstillingene lagres med anlegget, valideres i `prosjektform.js` og kan angres (`App.merk`).
- Kodestil: norske navn; kommentarene forklarer hvorfor («HER STO … Nå …»).

**Interfaces:**
- `RorPlan.brekk(z:number[], h:number) → [{ i, type: 'hoy'|'lav' }]`. Den går i sikksakk med terskel, og endene teller ikke.
- Merknadene fra `kontroller` får typene `hoybrekk` og `lavbrekk`, og `fall` med «for trykkrør».
- Kravet er kodens `minFall` bare når kodens egen regel er trykk; ellers `mal.trykkMinFall`. Kravet 0 er av.

- [x] Prøver for `brekk`:
  - kolle, dal, tuer under terskelen, jevn stigning;
  - topp–dal–topp, hull, og dal rett etter starten.
- [x] Prøver for `kontroller`:
  - ett høybrekk over en kolle, lavbrekk i en dal;
  - krav av, krav på, og kodens krav foran anleggets;
  - terskelen kan settes;
  - selvfall får ingen brekk;
  - en selvfallskode satt til trykk tar ikke med seg selvfallskravet.
