# 3D på skjermkortet, etappe 2 – implementeringsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Himmel og dis når man står i modellen, slagskygger fra sola i alle visninger – bare på skjermkortet.

**Architecture:** Alt ligger i `public/js/gl3d.js`. Et eget himmelprogram (fullskjermstrekant) tegnes først i bildet når `R.himmel`. Hovedshaderen får dis (`uTake`), omgivelseslys og skygge fra et skyggekart. Skyggekartet er et ortografisk dybdebilde fra sola, bygd bare når settet av ugjennomsiktige mesher endrer seg. `Tegner3d.tegn()` setter bare `R.himmel` og `R.take`.

**Tech Stack:** WebGL2, GLSL ES 3.00 (`sampler2DShadow`), ingen biblioteker.

**Spec:** `docs/superpowers/specs/2026-10-12-gpu-3d-etappe2-design.md`

## Global Constraints

- Prosessorveien uendret. Id- og dybdepassene uendret (`gpuSammeBilde` ≥ 97 %).
- Sola = lyset: retning (−0,4, 0,4, 0,82). Skygge fjerner bare direkte lys: `ly = 0,55 + 0,45·(n·l)·skygge`; baksider 0,45 som før.
- Himmel, dis og omgivelseslys bare når `kam.oye` (Fly og Gå). Ovenfra: samme bakgrunn som før.
- Dis: `f = 1 − exp(−(w/L)^1,3)`, `L = 2500 + 6·kamH`; tones mot `HORISONT = (0,80, 0,86, 0,92)`, samme farge som himmelen ved horisonten.
- Skyggekart: 1024–4096², ≤ ca. 0,5 m per teksel, PCF 3×3, normalforskyvning 1,5 teksel.
- Bildetid i `gpuGlatt` fortsatt ≤ 16 ms.

```js
  /* ---------------- lys og luft ---------------- */
  async gpuLysOgLuft() {
    if (typeof Gl3d === 'undefined' || !Gl3d.klar()) { this.hoppOver('lys og luft', 'WebGL2 finnes ikke'); return; }
    const rodt = (255 << 24) | (40 << 16) | (40 << 8) | 220;
    const lagGitter = (nb, nh, steg, z) => {
      const n = nb * nh, g = { nb, nh, wx: new Float64Array(n), wy: new Float64Array(n),
        finnes: new Uint8Array(n).fill(1), midtX: 500000, midtY: 6600000, maksAvvik: 1 };
      const h = new Float32Array(n);
      for (let j = 0; j < nh; j++) for (let i = 0; i < nb; i++) {
        const k = j * nb + i;
        g.wx[k] = 500000 + (i - (nb - 1) / 2) * steg; g.wy[k] = 6600000 + (j - (nh - 1) / 2) * steg;
        h[k] = z(i, j);
      }
      return { g, lag: { hoyde: h, farge: () => rodt } };
    };
    const px = (R, x, y) => {
      Gl3d.tegn(R);
      const l = document.createElement('canvas'); l.width = R.rb; l.height = R.rh;
      const k = l.getContext('2d'); k.drawImage(Gl3d.lerret, 0, 0);
      return k.getImageData(x, y, 1, 1).data;
    };

    /* SKYGGE: en søyle på 30 m midt på en flate. Sola står i nordvest, så
       skyggen faller mot sørøst. Kamera rett ned: x mot høyre, nord opp. */
    const { g, lag } = lagGitter(41, 41, 1, (i, j) => (Math.abs(i - 20) <= 1 && Math.abs(j - 20) <= 1) ? 130 : 100);
    Gl3d.nyttBilde(g);
    const m = Gl3d.mesh(g, lag, 1, 'lys-søyle');
    const rb = 400, rh = 400;
    const R = { rb, rh, bak: [0, 0, 0], horisont: null, fjern: 50000, himmel: false, take: 0,
      kam: { ox: g.midtX, oy: g.midtY, oz: 100, ov: 1, ca: 1, sa: 0, cp: 0, sp: 1,
        D: 100, F: 800, cx: rb / 2, cy: rh / 2, naer: 1, oye: null },
      liste: [{ m, modus: 'opak', blanding: 0, id: true }] };
    const ved = (x, y) => [rb / 2 + 8 * x, rh / 2 - 8 * y];
    const sum = p => p[0] + p[1] + p[2];
    const skygge = px(R, ...ved(8, -8)), sol = px(R, ...ved(-8, 8)), side = px(R, ...ved(8, 8));
    this.sjekk('bakken bak søyla ligger i skygge', sum(skygge) < sum(sol) * 0.8,
      sum(skygge) + ' mot ' + sum(sol));
    this.sjekk('  og bakken ved siden av gjør det ikke', Math.abs(sum(side) - sum(sol)) <= 6,
      sum(side) + ' mot ' + sum(sol));
    this.sjekk('  og skyggen er aldri mørkere enn 0,55 av fargen', skygge[0] >= Math.floor(220 * 0.55) - 2,
      String(skygge[0]));
    R.skygger = false;
    const uten = px(R, ...ved(8, -8));
    this.sjekk('  (uten skygger er den like lys som solsiden, så prøven måler noe)',
      Math.abs(sum(uten) - sum(sol)) <= 6, sum(uten) + ' mot ' + sum(sol));

    /* HIMMEL OG DIS: en flate på 2 km mot nord, øyet 1,7 m over den. */
    const s2 = lagGitter(41, 201, 10, () => 100);
    Gl3d.nyttBilde(s2.g);
    const m2 = Gl3d.mesh(s2.g, s2.lag, 1, 'lys-slette');
    const E = { x: s2.g.midtX, y: s2.g.midtY - 990, z: 101.7 };
    const p = 5 * Math.PI / 180;             // ser fem grader ned
    const R2 = { rb, rh, bak: [0, 0, 0], horisont: null, fjern: 50000, himmel: true, take: 300,
      kam: { ox: E.x, oy: E.y, oz: E.z, ov: 1, ca: 1, sa: 0, cp: Math.cos(p), sp: Math.sin(p),
        D: 0, F: (rh / 2) / Math.tan(30 * Math.PI / 180), cx: rb / 2, cy: rh / 2, naer: 0.35, oye: E },
      liste: [{ m: m2, modus: 'opak', blanding: 0, id: true }] };
    const topp = px(R2, rb / 2, 3);
    this.sjekk('himmelen øverst er blå', topp[2] > topp[0] + 20, [...topp].join(','));
    const horisontY = Math.round(rh / 2 - R2.kam.F * Math.tan(p));
    const nedeHimmel = px(R2, rb / 2, Math.max(4, horisontY - 6));
    this.sjekk('  og lysere ved horisonten enn oppe', sum(nedeHimmel) > sum(topp), sum(nedeHimmel) + ' mot ' + sum(topp));
    const HOR = [204, 219, 235];
    const avst = q => Math.hypot(q[0] - HOR[0], q[1] - HOR[1], q[2] - HOR[2]);
    const naer = px(R2, rb / 2, rh - 3), fjern = px(R2, rb / 2, horisontY + 3);
    this.sjekk('fjernt terreng er nærmere disen enn nært', avst(fjern) < avst(naer) * 0.5,
      Math.round(avst(fjern)) + ' mot ' + Math.round(avst(naer)));
    R2.take = 0; R2.himmel = false;
    const fjernUten = px(R2, rb / 2, horisontY + 3);
    this.sjekk('  (uten dis er det ikke det)', avst(fjernUten) > avst(fjern) * 2,
      Math.round(avst(fjernUten)) + ' mot ' + Math.round(avst(fjern)));

    /* SKYGGEKARTET BYGGES IKKE PÅ NYTT NÅR BARE KAMERAET FLYTTER SEG. */
    R.skygger = true;
    px(R, 0, 0);
    const foer = Gl3d.skyggekartBygd;
    for (let i = 0; i < 5; i++) { R.kam.ca = Math.cos(i / 5); R.kam.sa = Math.sin(i / 5); Gl3d.tegn(R); }
    this.sjekk('skyggekartet står når bare kameraet endres', Gl3d.skyggekartBygd === foer,
      (Gl3d.skyggekartBygd - foer) + ' bygg');

    /* I PROGRAMMET: himmel på bakken, ikke ovenfra. */
    if (App.resultat && App.resultat.profiler && Veg3d.lerret) {
      Veg3d.aktiver(true); Veg3d.nullstill();
      this.sjekk('ovenfra er det ingen himmel', Veg3d._gpuRamme && Veg3d._gpuRamme.himmel === false);
      Veg3d.settModus('bakken');
      this.sjekk('på bakken er det det', Veg3d._gpuRamme && Veg3d._gpuRamme.himmel === true && Veg3d._gpuRamme.take > 0);
      Veg3d.settModus('oversikt'); Veg3d.aktiver(false);
    }
  },
```

- [ ] **Step 3: Shaderne.** `_VS` får `uniform mat4 uLys; uniform float uNormOff; out vec4 vLys;` og til slutt `vLys = uLys * vec4(aPos + aNorm * uNormOff, 1.0);`. `_FS` byttes til:

```glsl
#version 300 es
precision highp float;
precision highp sampler2DShadow;
in vec3 vNorm;
in vec3 vVerden;
in float vW;
in vec4 vLys;
flat in vec3 vFarge;
flat in vec3 vId;
uniform int uPass;
uniform float uIdPa;
uniform vec2 uNF;
uniform vec4 uOye;
uniform sampler2DShadow uSkygge;
uniform float uSkyggePa;
uniform float uSkyggeTeksel;
uniform float uSkyggeBias;
uniform float uTake;
out vec4 ut;
const vec3 SOL = vec3(-0.4, 0.4, 0.82);
const vec3 HORISONT = vec3(0.80, 0.86, 0.92);
const vec3 HIMMELLYS = vec3(0.45, 0.60, 0.85);
float skygge() {
  if (uSkyggePa < 0.5) return 1.0;
  vec3 p = vLys.xyz * 0.5 + 0.5;
  if (p.x <= 0.0 || p.x >= 1.0 || p.y <= 0.0 || p.y >= 1.0 || p.z >= 1.0) return 1.0;
  float s = 0.0;
  for (int i = -1; i <= 1; i++)
    for (int j = -1; j <= 1; j++)
      s += texture(uSkygge, vec3(p.xy + vec2(float(i), float(j)) * uSkyggeTeksel, p.z - uSkyggeBias));
  return s / 9.0;
}
void main() {
  gl_FragDepth = clamp((vW - uNF.x) / (uNF.y - uNF.x), 0.0, 1.0);
  if (uPass == 1) { ut = uIdPa > 0.5 ? vec4(vId, 1.0) : vec4(0.0); return; }
  if (uPass == 2) { /* som før */ }
  vec3 n = normalize(vNorm);
  bool bakken = uOye.w > 0.5;
  bool bakside = bakken && dot(n, uOye.xyz - vVerden) < 0.0;
  float direkte = bakside ? 0.0 : clamp(dot(n, SOL), 0.0, 1.0) * skygge();
  float ly = bakside ? 0.45 : 0.55 + 0.45 * direkte;
  vec3 c = min(vFarge * ly, vec3(1.0));
  if (bakken) {
    c = mix(c, HIMMELLYS, 0.06 * (1.0 - direkte));
    if (uTake > 0.0) c = mix(c, HORISONT, 1.0 - exp(-pow(vW / uTake, 1.3)));
  }
  ut = vec4(c, 1.0);
}
```

Himmelen (fullskjermstrekant) og skyggen:

```glsl
// _HIMMEL_VS
#version 300 es
out vec2 vNdc;
void main() {
  vec2 p = vec2(float((gl_VertexID << 1) & 2), float(gl_VertexID & 2)) * 2.0 - 1.0;
  vNdc = p;
  gl_Position = vec4(p, 0.0, 1.0);
}
// _HIMMEL_FS – blikkretningen per piksel, kameraets formler snudd
#version 300 es
precision highp float;
in vec2 vNdc;
uniform vec4 uRot;
uniform vec4 uProj;
out vec4 ut;
const vec3 SOL = vec3(-0.4, 0.4, 0.82);
const vec3 HORISONT = vec3(0.80, 0.86, 0.92);
const vec3 SENIT = vec3(0.24, 0.45, 0.78);
const vec3 BAKKE = vec3(0.52, 0.56, 0.52);
void main() {
  float rx = (vNdc.x - uProj.y) / uProj.x;
  float sy = (uProj.w - vNdc.y) / uProj.z;
  float ry = -uRot.z + sy * uRot.w;
  float z = -uRot.w - sy * uRot.z;
  vec3 d = normalize(vec3(rx * uRot.x + ry * uRot.y, rx * uRot.y - ry * uRot.x, z));
  vec3 c = d.z >= 0.0 ? mix(HORISONT, SENIT, pow(d.z, 0.45))
                      : mix(HORISONT, BAKKE, clamp(-d.z * 5.0, 0.0, 1.0));
  float s = max(dot(d, normalize(SOL)), 0.0);
  c += vec3(1.0, 0.95, 0.8) * (pow(s, 800.0) * 1.5 + pow(s, 10.0) * 0.15);
  ut = vec4(min(c, vec3(1.0)), 1.0);
}
// _SKYGGE_VS / _SKYGGE_FS
#version 300 es
layout(location = 0) in vec3 aPos;
uniform mat4 uLys;
void main() { gl_Position = uLys * vec4(aPos, 1.0); }
#version 300 es
precision mediump float;
void main() {}
```

- [ ] **Step 4: JS.**
  - `_program(vs, fs, navn)` → `{p, u}`; `_lagProgram` bygger `_p/_u` (hoved), `_himmel`, `_skyggeP`, en tom VAO (`_tomVao`) og et 1×1 dybdetekstur med sammenligning (`_ingenSkygge`, dybde 1) bundet på enhet 1.
  - `_bygg`: `nr: ++this._meshNr` og `boks: [x0, y0, z0, x1, y1, z1]` over de nodene som finnes.
  - `_skyggekart(R)`: kastere = `opak` i `R.liste`; nøkkel = kasternes `nr` + origo; sola-aksene `f = −L`, `r = norm(f × ẑ)`, `u = r × f`; boks = alle meshenes hjørner i lysrommet + 2 m; størrelse = `min(4096, MAX_TEXTURE_SIZE, max(1024, 2^⌈log2(Δ/0,5)⌉))`; dybdetekstur `DEPTH_COMPONENT24` med `COMPARE_REF_TO_TEXTURE`/`LEQUAL`/`LINEAR`; tegnes med `polygonOffset(1.5, 3)`; `skyggekartBygd++`. Returnerer `{nokkel, mat, tex, fb, size, teksel, bias: 0.05/Δz}`.
  - `tegn(R)`: skyggekartet først (`R.skygger !== false`), så standardbufferet; himmel når `R.himmel` (dybde av), ellers som før; hovedprogrammet får `uLys`, `uNormOff = 1.5·teksel`, `uSkyggeTeksel = 1/size`, `uSkyggeBias`, `uSkyggePa`, `uTake = R.take || 0`.
  - `_glemAlt`: sletter skyggekartet (`_skygge = null`).
